# Web Research Skill

**Status:** Available from Claude Code local skills library (`~/.claude/skills/web`).

This is a general-purpose research skill that runs multi-angle searches on a legal question and returns one synthesized summary. It is used by the calendar-assistant and nd-cal-cmc-stmt-builder skills as needed for research tasks, and is also available as a direct tool for any other one-off research task.

The skill is not duplicated here; use it from your local Claude Code environment where it is already installed.
