# Templates Directory

This directory is reserved for reusable template snippets and partial documents.

## Planned Templates

- **standard_language_blocks.md** — Library of the 13 standard-language blocks (Evidence Preservation, Disclosures, Discovery, Class Actions, Related Cases, Settlement & ADR, Other References, Narrowing of Issues, Trial, Non-Party Entities, Professional Conduct, Other Matters) that are used verbatim in every CMS draft.
- **topic_templates/** — Individual topic templates (e.g., Topic 1 jurisdiction/venue, Topic 11 relief structure, Topic 15 scheduling table).
- **signature_block_templates/** — Signature block layouts for different counsel configurations.

For now, these are documented in `references/standing_order_topics.md` and will be extracted into separate files as the templates directory matures.
